# Welcome to React Debugger Discussions

> **Post in category:** Announcements
> **Recommended action after posting:** pin the discussion

---

👋 Welcome — this is the home for everything that isn't a bug report or a feature spec.

**React Debugger** is a Chrome DevTools panel that combines Timeline, Performance, Memory, Side Effects, Redux, CLS, and AI-powered analysis into a single tab. We're a small project trying to do one thing well: make React debugging not require switching between four tools.

## What we're working on right now

In active spec phase — see [`openspec/changes/mcp-server-v1/`](https://github.com/hoainho/react-debugger-extension/tree/main/openspec/changes/mcp-server-v1). First contributor PRs already landing.
