# Seed Discussions

Pre-written discussion threads for the maintainer to post into [GitHub Discussions](https://github.com/hoainho/react-debugger-extension/discussions) to bootstrap the category from 0 posts.

## How to use

1. Pick a file in this directory
2. Copy the body
3. Paste into a new discussion in the matching category (header at top of each file says which)
4. Hit "Start discussion"

This is one-time bootstrap content. Once posted, these files can be archived or kept as templates.

## Files

| File | Category | Purpose |
|---|---|---|
| `welcome.md` | Announcements | First post — sets community tone, points at issues/wiki/CONTRIBUTING |
| `roadmap-q3-2026.md` | Announcements | Public roadmap with milestone gates and dependencies |
| `ama-open-thread.md` | General | Standing "ask me anything" thread — pin it |

## Why pre-written?

A fresh Discussions surface with 0 posts looks dead. Seeding with 2-3 substantive threads from the maintainer signals "this is an active space," gives early visitors a concrete example of post quality, and makes the first community post feel less daunting ("oh, the maintainer posts here too").
